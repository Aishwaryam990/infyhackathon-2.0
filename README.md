# 🛒 TechNest

### Full-Stack E-Commerce Platform

TechNest is a secure and user-friendly e-commerce platform that makes online product discovery and shopping simple. It provides separate customer and admin experiences with secure authentication, product management, cart, wishlist, checkout, and order tracking.

## ✨ Key Features

### 👤 Customer

* Browse and search products
* View product details, price, discount, stock and reviews
* Add/remove products from wishlist
* Add, update and remove cart items
* Secure login and registration
* Simulated checkout and order placement
* View order history and order details

### 🔐 Admin

* Secure admin login
* Add, edit and delete products
* Manage product prices and stock
* Manage users
* View and manage customer orders
* Update order status
* Dashboard for monitoring store activity

## 🎯 Objective

TechNest aims to provide a complete e-commerce experience with a simple user interface, secure backend, efficient product management, and a dedicated admin dashboard.
